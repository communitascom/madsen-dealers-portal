MPSI Dealers Portal, layout study

Page layouts for the dealer portal, built inside what SharePoint delivers out of the box: native web parts and section settings only, no custom code.

The clickable prototype → Walk the portal as a dealer would. Twelve pages, working navigation. The layout panel → The same twelve pages with build notes, the state of each page's copy, and which native web part produces each block.

This is a study mockup, not the live portal. It grants no access to any Madsen system and carries no dealer data. Team names are withheld in this public preview: in the portal the People web part shows the real team from the Microsoft 365 directory.
