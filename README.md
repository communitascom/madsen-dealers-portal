# MPSI Dealers Portal, layout study

Page layouts for the Madsen Power Systems dealer portal, produced by Communitas.

Everything here is built from out-of-the-box SharePoint web parts and section
settings. No custom code, no SPFx.

- `prototipo.html` | clickable prototype, twelve pages with working navigation
- `painel.html` | the same pages with build notes and web part annotations
- `index.html` | landing page

## Not the live portal

This is a study mockup. It grants no access to any Madsen system and carries no
dealer data. Team names are withheld in this public preview; in the portal the
People web part shows the real team from the Microsoft 365 directory.
